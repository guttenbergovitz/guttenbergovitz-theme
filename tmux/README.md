# Guttenbergovitz for tmux

## Install

Add to your `~/.tmux.conf`:

```bash
# Dark theme
source-file /path/to/guttenbergovitz-theme/tmux/guttenbergovitz.tmux.conf

# Or light theme
source-file /path/to/guttenbergovitz-theme/tmux/guttenbergovitz-light.tmux.conf
```

Then reload: `tmux source-file ~/.tmux.conf`

## With TPM

If using [TPM](https://github.com/tmux-plugins/tpm), copy the theme file to `~/.tmux/themes/` and source it.
