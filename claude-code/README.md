# Guttenbergovitz for Claude Code

## Install

Copy theme to Claude Code themes directory:

```bash
mkdir -p ~/.claude/themes
cp guttenbergovitz.json ~/.claude/themes/
cp guttenbergovitz-light.json ~/.claude/themes/
```

Then in Claude Code:
```
/theme
```

Select "Guttenbergovitz" or "Guttenbergovitz Light".

## Alternative: tweakcc

```bash
npx tweakcc
```

Then import the theme JSON.
